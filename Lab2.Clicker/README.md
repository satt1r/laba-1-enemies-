# Лаба 2 — игра-кликер

Папка для следующего проекта. Код кликера пока не добавлен.

Основные части:

- `BigNumber`: хранение неотрицательных целых чисел блоками, ручная арифметика и неизменяемость.
- Игрок: золото, урон, стоимость улучшения и методы изменения состояния.
- Активный противник: текущее здоровье, награда и получение урона.
- Хранилище шаблонов: загрузка JSON, нормализация шансов и выбор противника.
- WPF-интерфейс: атака кликом и покупка улучшений.

Общие иконки и пример JSON находятся в `../assets/`. Редактор из первой лабы остаётся самостоятельным проектом в `../Lab1.EnemyEditor/`.
